1. 午夜的耳语 / Полуночный Шёпот  
*Тревога → Спокойствие*  
Состав: Улун, лавандовый сироп, кокосовое молоко, ванильный сироп, лёд. Топпинг: Тапиока.

2. 太阳 вспышка / Солнечная Вспышка  
*Усталость → Энергия*  
Состав: Зелёный чай (матча), имбирный сироп, манговый сироп, газированная вода.

3. 雾桥 / Туманный Мост  
*Неопределённость → Ясность*  
Состав: Чёрный чай (крепкий), грейпфрутовый сироп, тоник, лёд, долька грейпфрута.

4. 天鹅绒 мятеж / Бархатный Бунт  
*Подавленность → Бунтарство*  
Состав: Чёрный чай, вишнёвый сироп, клубничное пюре, безлактозное молоко. Топпинг: Тапиока, взбитые сливки.

5. 星云 мечта / Туманность Мечты  
*Скука → Вдохновение*  
Состав: Чай Каркаде, сироп личи, кокосовое молоко, синий клубничный сироп (слоями).

6. 无声 буря / Тихая Буря  
*Гнев → Баланс*  
Состав: Пуэр, гранатовый сироп, мятный сироп, лёд с ягодой внутри.

7. 纸帆 / Бумажный Парус  
*Одиночество → Лёгкость*  
Состав: Белый чай, мёд, персиковый сироп, игристый белый виноградный сок.

8. 生锈 компас / Ржавый Компас  
*Потерянность → Направление*  
Состав: Чай Каркаде, облепиховый сироп, имбирный сироп, мёд, горячий. Топпинг: Палочка корицы.

9. 量子 пена / Квантовая Пена  
*Перегруз → Фокус*  
Состав: Зелёный чай, сироп маракуйи, миндальное молоко. Топпинг: Взбитые сливки, тёртое печенье.

10. 琥珀 тюрьма / Янтарная Тюрьма  
*Зависимость → Освобождение*  
Состав: Чёрный чай, апельсиновый сироп, карамельный сироп, обычное молоко. Украшение: карамельная сетка.

11. 羊毛毯 / Шерстяное Одеяло  
*Холод → Уют*  
Состав: Чай Каркаде, миндальное молоко, мёд, сироп корицы, горячий. Посыпать молотой корицей.

12. Угасающее Эхо / 褪色回声  
*Ностальгия → Принятие*  
Состав: Улун, персиковый сироп, розовый сироп, лёд. Топпинг: Тапиока, сушёная роза.

13. 火山 пепел / Вулканический Пепел  
*Апатия → Пробуждение*  
Состав: Чёрный чай (крепкий), ананасовый сок, лаймовый сироп, лёд. Топпинг: Тёртое печенье «орео».

14.  жестяной солдат / Жестяной Солдат  
*Хрупкость → Стойкость*  
Состав: Чёрный чай, имбирный сироп, мёд, кленовый сироп, горячий.

15. забытый язык / 被遗忘的语言  
*Недопонимание → Гармония*  
Состав: Зелёный чай, грушевый сироп, лёд. Украсить долькой груши.
