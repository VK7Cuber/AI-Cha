# AI-Cha
This is the official Github repository of a cafe AI Cha (爱茶). This is a cafe specializing in tea sales. This repository contains the code of the control program for the terminal with a built-in AI agent that helps customers choose the right drinks according to their moods and preferences. 
In the Terminal branch, you can find the program code that controls a terminal with built-in artificial intelligence. In the Documentation branch, you can see all the documentation and additional files related to the project.
