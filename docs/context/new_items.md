1. 午夜的耳语 / Полуночный Шёпот  
*Тревога → Спокойствие*  
Состав: Улун, лавандовый сироп, кокосовое молоко, ванильный сироп, лёд. Топпинг: классическая Тапиока.

2. 太阳  / Солнечная Вспышка  
*Усталость → Энергия*  
Состав: Зелёный чай (матча), имбирный сироп, манговый сироп, газированная вода.

3. 雾桥 / Туманный Мост  
*Неопределённость → Ясность*  
Состав: Чёрный чай (крепкий), апельсиновый сироп, тоник, лёд, долька грейпфрута.

4. 天鹅绒 / Бархатный Бунт  
*Подавленность → Бунтарство*  
Состав: Чёрный чай, малиновый сироп, безлактозное молоко. Топпинг: клубничная Тапиока, взбитые сливки.

5. 星云  / Туманность Мечты  
*Скука → Вдохновение*  
Состав: Чай белый «Бай му Дань»сироп цветков сливы, кокосовое молоко.

6. 无声 / Тихая Буря  
*Гнев → Баланс*  
Состав: молочный улун, мятный сироп, кокосовый сироп, лёд 

7. 纸帆 / Бумажный Парус  
*Одиночество → Лёгкость*  
Состав: Белый чай Бай му Дань, мёд, лавандовый сироп, кокосовый сироп, тапиока с матчей 

8. 生锈 / Ржавый Компас  
*Потерянность → Направление*  
Состав: Чай черный, апельсиновый сироп, имбирный сироп, мёд, горячий. Топпинг: Палочка корицы.

9. 量子  / Квантовая Пена  
*Перегруз → Фокус*  
Состав: Зелёный чай с жасмином, сироп манговый, миндальное молоко. Топпинг: Взбитые сливки.

10. 琥珀 / Янтарная Тюрьма  
*Зависимость → Освобождение*  
Состав: Чёрный чай, апельсиновый сироп, карамельный сироп, обычное молоко. Украшение: карамельная сетка.

11. 羊毛毯 / Шерстяное Одеяло  
*Холод → Уют*  
Состав: Чай черный мятный , миндальное молоко, мёд, сироп корицы, горячий. Посыпать молотой корицей. и добавить медовую тапиоку 

12. 褪色回声 / Угасающее Эхо
*Ностальгия → Принятие*  
Состав: чай молочный улун, мятный сироп, шоколадный  сироп, лёд. Топпинг: Тапиока.

13. 火山 / Вулканический Пепел  
*Апатия → Пробуждение*  
Состав: Чёрный чай (крепкий), карамельный сироп, апельсиновый сироп лёд.

14.  士兵 / Жестяной Солдат  
*Хрупкость → Стойкость*  
Состав: Чёрный чай, имбирный сироп, мёд, кленовый сироп, горячий.

15. 被遗忘的语言 / Забытый язык
*Недопонимание → Гармония*  
Состав: Зелёный чай жасминовый, миндальный сироп, фундуковый сироп, лёд, тапиока
