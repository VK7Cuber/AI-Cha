# Технологический стек AI-Cha Terminal

## Общая архитектура проекта

AI-Cha Terminal — это комплексная система самообслуживания для кафе, состоящая из нескольких взаимодействующих компонентов:

- **Frontend** — пользовательский интерфейс терминала (React + TypeScript)
- **Backend** — серверная часть с API и бизнес-логикой (Node.js + Fastify)
- **AI Layer** — слой искусственного интеллекта для голосового диалога и генерации рецептов
- **Database** — реляционная база данных PostgreSQL для хранения всех данных
- **Cache** — Redis для кэширования и повышения производительности
- **Infrastructure** — Docker контейнеры с Nginx как reverse proxy

Архитектура построена по принципу **микросервисов в монорепозитории**, где каждый компонент изолирован, но тесно интегрирован с другими через четко определенные API.

## Frontend (Пользовательский интерфейс)

### Основные технологии
- **React 18** — современная библиотека для построения пользовательских интерфейсов
- **TypeScript 5** — типизированный JavaScript для повышения надежности кода
- **Vite** — быстрый сборщик и dev-сервер для современной фронтенд-разработки
- **React Router 6** — маршрутизация между экранами терминала

### Стилизация и UI
- **Tailwind CSS 3** — utility-first CSS фреймворк для быстрой стилизации
- **Framer Motion** — библиотека для сложных анимаций и переходов
- **Lottie React** — воспроизведение векторных анимаций (для AI-агента)
- **PostCSS + Autoprefixer** — обработка CSS и добавление вендорных префиксов

### Управление состоянием
- **Zustand** — легковесная библиотека для управления состоянием приложения
- Отдельные store для:
  - `cartStore` — корзина и заказы
  - `productsStore` — каталог товаров
  - `navigationStore` — навигация и роутинг
  - `themeStore` — светлая/темная тема

### Сетевые запросы и API
- **Axios** — HTTP клиент для взаимодействия с backend API
- **React Hot Toast** — уведомления и сообщения об ошибках
- Сервисы для работы с API:
  - `api.ts` — базовая конфигурация Axios
  - `productService.ts` — работа с каталогом товаров
  - `orderService.ts` — управление заказами
  - `ratingService.ts` — система оценок

### Архитектура компонентов
```
src/
├── components/           # Переиспользуемые компоненты
│   ├── common/          # Базовые UI компоненты (Button, Card, Modal)
│   ├── screens/         # Экраны терминала (Welcome, Catalog, Cart)
│   ├── products/        # Компоненты для работы с товарами
│   └── animations/      # Анимированные компоненты
├── hooks/               # Пользовательские React хуки
├── services/            # Сервисы для API
├── store/               # Zustand stores
├── types/               # TypeScript типы
└── styles/              # Глобальные стили и цвета
```
### Особенности для терминала
- **Адаптация под сенсорный экран 10.1"** — крупные элементы, удобное касание
- **Поддержка двух языков** — русский и китайский интерфейс
- **Светлая и темная темы** — переключение через CSS переменные
- **Автономная работа** — frontend может работать без интернета (PWA-готовность)

## Backend (Серверная часть)

### Основные технологии
- **Node.js 18+** — серверная JavaScript среда выполнения
- **Fastify 4** — быстрый и низкоуровневый веб-фреймворк (альтернатива Express)
- **ES Modules** — современный модульный подход JavaScript

### Архитектура и структура
```
src/
├── api/                 # API слой
│   ├── controllers/     # Контроллеры для обработки запросов
│   ├── routes/          # Определение маршрутов API
│   └── middleware/      # Промежуточные обработчики
├── services/            # Бизнес-логика
├── database/            # Работа с базой данных
│   ├── models/          # Sequelize модели
│   ├── migrations/      # Миграции схемы БД
│   └── seeds/           # Начальные данные
├── config/              # Конфигурация приложения
└── utils/               # Вспомогательные функции
```

### База данных и ORM
- **PostgreSQL 15** — надежная реляционная СУБД
- **Sequelize 6** — популярный ORM для Node.js
- **pg** — нативный драйвер PostgreSQL для Node.js

### Безопасность и производительность
- **@fastify/helmet** — HTTP заголовки безопасности
- **@fastify/cors** — настройка Cross-Origin Resource Sharing
- **@fastify/compress** — gzip сжатие ответов

### Логирование и мониторинг
- **Pino** — быстрое структурированное логирование
- **pino-pretty** — красивое форматирование логов в development

### WebSocket для AI
- **ws** — библиотека для WebSocket соединений
- Используется для потоковой передачи аудио между терминалом и AI-сервисами
- Обработка binary данных (аудио) и JSON сообщений

### Дополнительные библиотеки
- **uuid** — генерация уникальных идентификаторов
- **dotenv** — загрузка переменных окружения из .env файлов
- **date-fns** — работа с датами и временем

## AI Layer (Искусственный интеллект)

### Голосовые технологии
- **Yandex SpeechKit** — Speech-to-Text и Text-to-Speech
  - Потоковое распознавание речи (gRPC streaming)
  - Естественный синтез речи на русском языке
  - Voice Activity Detection для определения начала/конца речи

### Языковые модели
- **GigaChat API (Sber)** — основная модель для диалога
  - OAuth 2.0 авторизация с автообновлением токенов
  - Генерация диалогов и персонализированных рецептов
  - Анализ настроения пользователя из контекста беседы

- **Llama-3 8B** — локальная fallback-модель
  - Работает без интернета через Ollama/llama.cpp
  - Квантизация Q4/Q8 для экономии памяти
  - Автоматическое переключение при недоступности облачной модели

### Аудио обработка
- **Opus codec** — эффективное сжатие аудио для передачи
- **Web Audio API** — захват звука с микрофона в браузере
- **WebSocket** — потоковая передача аудио в реальном времени

### AI-специфичные компоненты
```
backend/src/ai/
├── services/
│   ├── sttService.js        # Speech-to-Text интеграция
│   ├── ttsService.js        # Text-to-Speech интеграция
│   ├── aiModelService.js    # Работа с языковыми моделями
│   ├── dialogService.js     # Управление диалогами
│   ├── analysisService.js   # Анализ ответов пользователя
│   └── recipeGenerator.js   # Генерация уникальных рецептов
├── prompts/                 # Промпты для AI-моделей
└── config/                  # Конфигурация AI-сервисов
```

## Базы данных и кэширование

### PostgreSQL (Основное хранилище)
Реляционная база данных для хранения всей информации системы:

**Основные таблицы:**
- `products` — каталог товаров кафе
- `categories` — категории товаров
- `ingredients` — ингредиенты для рецептов
- `orders` + `order_items` — заказы клиентов
- `ratings` — оценки товаров от клиентов

**AI-специфичные таблицы:**
- `dialog_sessions` — сессии диалогов с AI
- `dialog_messages` — сообщения в диалогах
- `user_profiles` — профили пользователей из диалогов
- `generated_recipes` — уникальные рецепты, созданные AI
- `ingredient_compatibility` — совместимость ингредиентов

### Redis (Кэширование)
Высокопроизводительное кэширование для:
- **TTS кэш** — синтезированные аудио фразы (экономия времени и API-запросов)
- **Сессии диалогов** — временное хранение активных AI-диалогов
- **Каталог товаров** — кэширование частых запросов к продуктам
- **Ингредиенты** — кэш данных для генерации рецептов

### Миграции и seeds
- **Sequelize CLI** — управление схемой базы данных через миграции
- **Seeds** — заполнение начальными данными (товары, ингредиенты, базовые рецепты)
- Версионирование схемы БД для безопасных обновлений

## Инфраструктура и развертывание

### Docker контейнеризация
Вся система работает в Docker контейнерах для изоляции и простоты развертывания:

- **postgres:15-alpine** — база данных PostgreSQL
- **redis:7-alpine** — кэш Redis
- **backend** — Node.js приложение (custom образ)
- **frontend** — статические файлы React (custom образ)
- **nginx:alpine** — reverse proxy сервер

### Nginx Reverse Proxy
- **Маршрутизация запросов:**
  - `/api/*` → backend:8080 (API запросы)
  - `/*` → frontend:80 (статические файлы и SPA)
- **Сжатие gzip** для статических ресурсов
- **Кэширование** статических файлов
- **Проксирование заголовков** для корректной работы

### Сеть и порты
- **Nginx:80** — единая точка входа для всех запросов
- **Backend:8080** — внутренний порт API (недоступен снаружи)
- **PostgreSQL:5432** — доступ к базе данных для разработки
- **Redis:6379** — доступ к кэшу для разработки

### Volumes и персистентность
- `postgres_data` — хранение данных PostgreSQL
- `redis_data` — хранение данных Redis
- Конфигурационные файлы примонтированы как read-only volumes

## Взаимодействие компонентов

### Поток данных в системе

1. **Пользователь взаимодействует с терминалом:**
   - Frontend (React) отображает интерфейс на сенсорном экране
   - Пользователь выбирает товары или запускает AI-диалог

2. **API-запросы через Nginx:**
   - Все `/api/*` запросы проксируются на Backend
   - Статические файлы отдаются напрямую из Frontend контейнера

3. **Обработка на Backend:**
   - Fastify обрабатывает HTTP-запросы
   - Контроллеры используют сервисы для бизнес-логики
   - Sequelize взаимодействует с PostgreSQL

4. **AI-диалог (если выбран AI-режим):**
   - WebSocket соединение Frontend ↔ Backend
   - Потоковая передача аудио → Yandex STT
   - Анализ речи → GigaChat API
   - Синтез ответа → Yandex TTS
   - Генерация персонального рецепта

5. **Кэширование:**
   - Redis кэширует частые запросы и TTS-аудио
   - Снижение нагрузки на внешние API

6. **Сохранение данных:**
   - Заказы, рецепты, диалоги сохраняются в PostgreSQL
   - Аналитические данные для улучшения AI

### Обработка ошибок и fallback
- **AI недоступен** → переход на обычный режим каталога
- **STT/TTS ошибки** → текстовый интерфейс диалога
- **GigaChat недоступен** → автоматическое переключение на Llama-3
- **База данных недоступна** → graceful degradation с уведомлением

## Развертывание и эксплуатация

### Development окружение
```bash
# Запуск всех сервисов в Docker
docker-compose up -d

# Отдельная разработка Frontend
cd frontend && npm run dev

# Отдельная разработка Backend  
cd backend && npm run dev
```

### Production окружение
- **Docker Compose** для оркестрации всех сервисов
- **Nginx** как единая точка входа и load balancer
- **Автоматические миграции** при обновлении схемы БД
- **Health checks** для всех критичных сервисов
- **Логирование** всех компонентов с ротацией логов

### Мониторинг
- **Структурированные логи** (JSON) для анализа
- **Метрики AI** — латентность, успешность диалогов
- **API метрики** — время ответа, количество ошибок  
- **Бизнес метрики** — конверсия, средний чек, популярные товары

### Безопасность
- **CORS политики** для защиты от XSS
- **Helmet.js** для HTTP заголовков безопасности
- **Валидация входных данных** на Backend
- **Rate limiting** для API endpoints
- **Secure cookies** и HTTPS в production
